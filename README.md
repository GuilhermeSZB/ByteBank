# 🏦 ByteBank

> Um sistema bancário desenvolvido em Java, criado para transformar meus estudos de Programação Orientada a Objetos em um projeto funcional.

## 📌 Sobre o projeto

O **ByteBank** é um sistema bancário desenvolvido em Java com o objetivo de aplicar, na prática, os conceitos que venho aprendendo durante meus estudos de Programação Orientada a Objetos.

A ideia é começar com um sistema simples de terminal e evoluí-lo conforme novos conhecimentos forem sendo adquiridos.

Este projeto não nasceu pronto.

Ele vai crescer junto com meu aprendizado em Java. 🚀

---

## 🎯 Objetivo

Criar um sistema bancário capaz de realizar operações básicas, como:

- Criar contas
- Consultar dados
- Depositar dinheiro
- Realizar saques
- Verificar saldo
- Realizar transferências
- Trabalhar com diferentes contas e clientes

Conforme o projeto evoluir, novas funcionalidades serão adicionadas.

---

## 🧠 O que estou praticando

Durante o desenvolvimento estou colocando em prática conceitos como:

- Programação Orientada a Objetos

- Construtores

Novos conceitos serão adicionados ao projeto conforme forem estudados.
